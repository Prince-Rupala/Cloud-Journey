## Difference between image and container?

Image is like a blueprint of a house, while container is the pyhsical house itself that was built from the blueprint.


## What does docker start do?

Docker start is used to reopen the container, but you are not attached to it.


## What does docker stop do?

Docker stop gracefully stops a running container by terminating its main process.


## What does docker exec -it do?

It is used to enter a running container.


## What happened to the file after re-entering the container?

When i re-entered the container, the file is as it is as it was before.


## What is the lifecycle of a container?

1. Created: You have generated the container from an image.
2. Running: The container is active and it is executing its processes.
3. Paused:  The container's processes are frozen in place.
4. Exited:  The container's primary process has shut down.
5. Destroyed: The container is permanently deleted from your computer.
