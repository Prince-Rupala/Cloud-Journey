## What Does if Do?

It makes the decision based on a condition. It tells the script: "If this statement is true, run the code inside. If it is false, skip it."

## Most Useful Operator

Every operator is useful

## Difference Between -f and -d

-f: Checks if the file exists and is a regular file.
-d: Checks if the directory exists and is a folder.
