# Day 16


## What is a Git branch?

An isolated, independent timeline of your code. It's a separate sandbox where you can modify files without touching the main project.


## Why use brances?

To work on multiple tasks (like fixing a bug and building a new page) at the same time without the code changes clashing or breaking each other.


## What does git switch do?

To jump back and forth between timelines.


## What does git merge do?

It combines the history and code changes of two branches together. Usually, you use it to pull completed work from a feature branch back into your main branch.


## Why is branching safer than working directly on main?

Because main usually holds your stable, working version. Branching acts like a "Save As" copy: if you make a mistake or break the code, you can just delete the experimental branch, and your live, functional code on main remains untouched.
