# Day 17


## What is origin?

The default nickname Git gives to the central remote server (like GitHub) where your project's online repository lives.


## What does git clone do?

Downloads an entire online repository—including all files, folders, and history—onto your local computer for the very first time.


## Difference between fit fetch and git pull?

git fetch: Downloads new data from the remote server but does not touch your local working files. It just updates your system's map of what's online.

git pull: Downloads the new data and immediately merges it directly into your local files, changing your code instantly.


## Why would a team use a remote repository?

It acts as a single, centralized "source of truth" in the cloud. It allows multiple developers to share code, sync changes, and back up their work in one secure place.


## What happens during a push?

Your local commits are uploaded and synced to the remote repository, making your updates visible to the rest of the team.
